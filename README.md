# Feedback do Portal de Cursos IFMA

Este repositório recebe bugs e propostas de melhoria do [Portal de Cursos IFMA](https://cursos.mindsresearch.com.br/imperatriz/bcc).

[Abrir uma issue](https://github.com/Forte-Tecnologias/portal-cursos-feedback/issues/new/choose) · [Acompanhar o Project](https://github.com/orgs/Forte-Tecnologias/projects/7)

Antes de abrir uma issue, procure se alguém já relatou o mesmo problema. Registre um problema ou uma proposta por issue e escolha o modelo **Bug** ou **Melhoria**.

Use o título `[Bug][Área] problema observado` ou `[Melhoria][Área] mudança proposta`. Informe o link da página, os passos para conferir a situação e uma captura de tela ou vídeo. Para um bug, descreva o comportamento atual e o esperado. Para uma melhoria, explique a dificuldade, a proposta e o benefício.

As novas issues entram automaticamente no Project. O quadro é público para consulta. O professor acompanha e organiza os relatos.

Quem participa da atividade de POO deve informar nome e turma para identificar sua contribuição, sem matrícula. Use dados de demonstração e oculte senhas, notas e informações pessoais nas evidências.

Este repositório contém os relatos e seus modelos. O código do portal fica em um repositório separado.
